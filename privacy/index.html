Privacy policy

Website name: Croveli | Crochet Patterns.

This page explains the data used by the current Croveli website.

Saved on your device

Croveli uses local browser storage for your saved pattern IDs, materials checklists, completed instruction steps, resume position, text-size preference, and project notes. This information is not sent to a Croveli account or server. Project notes can include the name and text you enter.

Saved information stays in this browser until you remove it or clear site data. It does not automatically sync across devices. Private browsing or blocked storage can prevent it from being retained.

Manage saved patterns, or use the control below to clear all Croveli browser data, including progress and notes.

Manage browser data

Clearing all Croveli data removes saved patterns, material checks, instruction progress, reading preferences, and project notes from this browser.

Contact and newsletter

Using an email link opens your email app. Messages are sent only when you choose to send them through that app; Croveli receives the information you include.

Newsletter signup is not open. No newsletter email addresses are collected on this website.

Hosting and external links

The local preview is served from your computer. The public website uses GitHub Pages. GitHub states that it records visitors’ IP addresses for security when they visit a GitHub Pages site. See GitHub Pages data collection and its privacy statement.

Croveli currently has no analytics, advertising scripts, embedded videos, or external font requests. Following an external link takes you to another service with its own privacy practices.

Privacy questions

Contact elmokanass4@gmail.com with questions about information you send to Croveli.
